# Установка и подключение

Собери собственный форк из Git и укажи абсолютный путь к его `dist/index.js` в настройках MCP-клиента. Нужен Node.js 24+. Пакет `@h2nguyen/arc42-node-mcp-server` — upstream; он не содержит product-профиля.

Каноническая инструкция: [docs/how-to/install.md](../../../../docs/how-to/install.md). Она содержит clone/build, настройку клиента, проверку stdio, установку Skill и процедуру получения upstream-обновлений.

Сервер выбирает проект: абсолютный targetFolder конкретного вызова → аргумент запуска → текущий каталог процесса. Product обнаруживается по `.arc42.yaml`; upstream — по `arc42-docs/config.yaml`. Если обнаружены оба, сначала вручную разреши конфликт источников конфигурации. Не переинициализируй такой проект.

После обновления сервера пересобери dist, перезапусти MCP-клиент и обнови установленную копию Skill вместе с references.
