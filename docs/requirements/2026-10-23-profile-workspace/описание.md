# Требование

Расширить форк Arc42 MCP Server для построения, ведения, проверки и постепенной миграции документации. Сохранить шесть существующих MCP tools, 11 языков, Markdown/AsciiDoc и историю upstream.

Новый настраиваемый профиль должен поддерживать многофайловый arc42, вложенные Building Blocks, runtime-сценарии, отдельные MADR, YAML frontmatter и инициализацию проекта. Редактирование должно проверять версию документа и менять только однозначно выбранный фрагмент. Валидатор проверяет структуру, ссылки, метаданные и связи документов. Инвентаризация и план миграции не меняют исходные материалы.

Нормативный профиль: [редакция 2026-10-12](https://drive.google.com/file/d/18g_j2ehMx76VEU0RKGZ_lTD90Am3EyVA/view). Официальные источники: [arc42](https://docs.arc42.org/), [MADR 4](https://adr.github.io/madr/). Локальные правила являются отдельным выбором продукта, а не требованиями arc42.

Результат: работающий stdio MCP, актуальный Skill, инструкция установки, тесты, отчёт совместимости. Работа ведётся небольшими коммитами по циклу Ponytail → Validator → Critic → исправления → повторная проверка → holistic audit.
